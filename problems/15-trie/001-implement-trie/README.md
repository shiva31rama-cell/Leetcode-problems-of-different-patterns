# Implement Trie

A Trie (prefix tree) stores characters along shared paths. It is useful when many operations ask whether a word exists or whether any word starts with a prefix.

Example: insert `cat` and `car`. `search("cat")` is true, `search("ca")` is false, and `startsWith("ca")` is true.

For a word of length L, insert, search, and prefix checks take O(L).

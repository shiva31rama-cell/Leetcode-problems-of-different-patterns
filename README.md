# Pattern-First DSA Course — Java + Python

This repository is a **pattern-first DSA learning system**.

The goal is not to collect thousands of repetitive questions. The goal is to learn reusable problem-solving patterns, recognize them quickly, implement them clearly in **Java and Python**, and then transfer the idea to problems from different coding platforms.

## What every module now contains

- **What is the topic?** — simple meaning and intuition
- **When do I use it?** — recognition clues
- **Core syntax** — Java + Python templates
- **Clear structured implementation** — readable variable names and comments
- **Sample input/output**
- **Test cases** — normal, edge, and variation cases
- **Complexity** — time and space
- **Common mistakes**
- **Variations and combinations**
- **Cross-platform practice mapping**

## Java and Python are separate learning tracks

The algorithms are conceptually shared, but the implementations intentionally use language-native structures and syntax.

### Java

Use the `courses/java/` material and `java/Solution.java` files.

Typical structures:

- `HashMap`
- `HashSet`
- `ArrayList`
- `ArrayDeque`
- `PriorityQueue`
- arrays and recursive methods

### Python

Use the `courses/python/` material and `python/solution.py` files.

Typical structures:

- `dict`
- `set`
- `list`
- `collections.deque`
- `heapq`
- functions and recursion

# Python — Simple to Medium Roadmap

The Python course teaches the same algorithmic patterns independently, using Python's natural data structures and syntax.

## Module template

For every pattern:

- `01-simple-example` — tiny problem that isolates the idea.
- `02-medium-example` — realistic interview-style problem.
- `03-variation` — same pattern with one changed condition.
- `04-combination` — combine the pattern with another technique.

## Recommended order

1. `dict` / `set`
2. Two pointers
3. Sliding window
4. Prefix sum
5. Binary search
6. List as stack + `collections.deque`
7. Monotonic stack
8. Linked-list pointers
9. Tree DFS / BFS
10. Graph DFS / BFS
11. `heapq`
12. Greedy
13. Backtracking
14. Dynamic programming
15. Trie
16. Bit manipulation

## Python style rules

- Prefer readable Python over clever one-liners.
- Explain important state changes.
- Use `dict` and `set` when constant-average-time lookup is the intended pattern.
- Use `deque` for queue behavior.
- Use `heapq` for heap behavior.
- Keep LeetCode method signatures simple and compatible.
- Include standalone examples when they improve learning.

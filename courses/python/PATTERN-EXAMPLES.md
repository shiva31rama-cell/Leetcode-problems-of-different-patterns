# Python Pattern Examples — Simple → Medium

This is the Python practice layer. Start with the simple version, then solve the medium bridge independently.

| Module | Simple example | Medium bridge |
|---|---|---|
| Hashing | frequency with `dict` | Group Anagrams |
| Two Pointers | pair in sorted list | 3Sum |
| Sliding Window | fixed-size sum | longest unique substring |
| Prefix Sum | running sums | Subarray Sum Equals K |
| Binary Search | target lookup | rotated sorted array |
| Stack | list as stack | bracket validation |
| Monotonic Stack | next greater element | Daily Temperatures |
| Linked List | middle node | cycle detection |
| Trees | preorder traversal | level-order traversal |
| Graphs | grid DFS | Number of Islands |
| Heap | keep smallest k | kth largest |
| Greedy | reachable boundary | Jump Game |
| Backtracking | choose/skip | generate subsets |
| DP | Fibonacci states | House Robber |
| Trie | character dictionary | prefix search |
| Bit | bit test | XOR single number |

## Python syntax checklist
- Lists: `list[int]`
- Dictionaries: `dict` or `{}`
- Sets: `set()`
- Stack: `list.append()` / `list.pop()`
- Queue: `collections.deque`
- Heap: `heapq`
- Strings: normal immutable `str`
- Tree/list nodes: small classes with references

## Study rule
Do not translate Java line by line. First describe the algorithm in plain English, then write Python using Python's natural data structures.

# Java — Simple to Medium Roadmap

The Java course is designed to teach the idea before the LeetCode implementation.

## Module template

For every pattern:

- `01-simple-example` — tiny problem that isolates the idea.
- `02-medium-example` — realistic interview-style problem.
- `03-variation` — same pattern with one changed condition.
- `04-combination` — combine the pattern with another technique.

## Recommended order

1. HashMap / HashSet
2. Two pointers
3. Sliding window
4. Prefix sum
5. Binary search
6. Stack / Deque
7. Monotonic stack
8. Linked-list pointers
9. Tree DFS / BFS
10. Graph DFS / BFS
11. PriorityQueue / heap
12. Greedy
13. Backtracking
14. Dynamic programming
15. Trie
16. Bit manipulation

## Java style rules

- Prefer clear variable names.
- Avoid unnecessary one-line tricks.
- Explain every important loop and state change.
- Use `ArrayDeque` for stack/queue behavior where appropriate.
- Use `PriorityQueue` for heap problems.
- Include a small `main` method in standalone learning examples when it helps beginners.
- Keep LeetCode submission classes compatible with the expected method signature.

# Java Pattern Examples — Simple → Medium

This is the Java practice layer. Each example is small enough to understand, but each demonstrates the same pattern used in the problem modules.

| Module | Simple example | Medium bridge |
|---|---|---|
| Hashing | frequency of numbers | Group Anagrams |
| Two Pointers | pair in sorted array | 3Sum |
| Sliding Window | fixed-size maximum sum | longest unique substring |
| Prefix Sum | range sum | Subarray Sum Equals K |
| Binary Search | find a target | rotated sorted array |
| Stack | reverse a string | bracket validation |
| Monotonic Stack | next greater element | Daily Temperatures |
| Linked List | find middle node | cycle detection |
| Trees | preorder traversal | level-order traversal |
| Graphs | DFS of a grid | Number of Islands |
| Heap | smallest k values | kth largest |
| Greedy | maximum reachable index | Jump Game |
| Backtracking | choose/skip one value | generate subsets |
| DP | Fibonacci states | House Robber |
| Trie | insert/search a word | prefix search |
| Bit | test a bit | XOR single number |

## Study rule
For each row: first write the simple example yourself, then solve the medium bridge without copying the solution. Afterward compare the invariant and complexity.

## Java syntax checklist
- Arrays: `int[]`
- Dynamic lists: `ArrayList<Integer>`
- Hashing: `HashMap`, `HashSet`
- Stack behavior: `ArrayDeque`
- Queue behavior: `ArrayDeque`
- Heap: `PriorityQueue`
- Strings: `String`, `StringBuilder`
- Tree/list nodes: small classes with references

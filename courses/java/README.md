## Java explanation standard

Every important line will be explained in plain English. We prefer readable code over compressed code.

Example:

```java
Map<Integer, Integer> frequency = new HashMap<>();
```

Meaning:

- `Map<Integer, Integer>` → key and value are both integers
- first `Integer` → the value being counted
- second `Integer` → its frequency
- `HashMap` → provides fast average lookup
- `frequency` → the variable storing the map

The same concept is then implemented independently in Python in the Python course.

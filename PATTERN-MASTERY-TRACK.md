# Pattern Mastery Track

This is the master learning sequence for the repository.

## How to use each pattern

1. Learn the simple example first.
2. Identify the trigger words and constraints.
3. Write the brute-force idea in plain English.
4. Derive the optimized pattern.
5. Dry-run the code by hand.
6. Implement it in Java.
7. Implement the same idea naturally in Python.
8. Solve the medium representative problem.
9. Solve one variation without looking at the solution.
10. Revisit the pattern after 1, 3, and 7 days.

## Difficulty progression

### Level A — Simple
Use small inputs and focus only on understanding the pattern.

### Level B — Medium
Add constraints, duplicates, edge cases, or a second idea.

### Level C — Advanced
Combine patterns or change the problem structure.

## Rule

Do not measure progress by the number of problems solved. Measure progress by the number of problems you can classify correctly before coding.

# Course Architecture

## Two Independent Implementations

This repository contains one conceptual DSA curriculum with two separate language tracks.

```text
                    DSA PATTERN MASTERY
                           |
             +-------------+-------------+
             |                           |
        JAVA COURSE                PYTHON COURSE
             |                           |
       Java syntax                 Python syntax
       Java collections            Python collections
       Java implementation         Python implementation
             |                           |
             +-------------+-------------+
                           |
                    SAME DSA PATTERN
```

## Learning Unit Structure

Every pattern is taught in this order:

1. Concept in simple language
2. Recognition clues
3. Core invariant/state
4. Basic example
5. Foundation problem
6. Core problems
7. Variations
8. Combined-pattern problems
9. Independent assessment
10. Revision checklist

## Problem Implementation Standard

For every selected problem, Java and Python receive separate solution files and separate syntax explanations. Code should be readable, beginner-friendly, and commented where logic is non-obvious. Avoid clever one-liners when they reduce clarity.

## Platforms

The catalog can contain problems originating from LeetCode, CodeChef, HackerRank, MentorPick, and other legitimate practice sources. Platform-specific problem statements are linked rather than copied wholesale.

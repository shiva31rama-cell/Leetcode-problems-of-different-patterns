# Expanded Cross-Platform Practice Roadmap 🚀

This file expands the seed catalog into a larger pattern-first practice pool. The goal is **coverage of techniques**, not solving every duplicate problem.

## How to use this list

For every pattern, solve in this order:

`Foundation → Core → Variation → Combination → Advanced`

For each selected problem use the same learning record:

- What is the topic?
- Recognition clues
- Syntax/template
- Brute force
- Optimized idea
- Invariant/state
- Visualize Mode
- Java implementation
- Python implementation
- Sample output
- Edge cases
- Test cases
- Complexity
- Common mistakes

## Selection rule

Do **not** automatically implement every listed problem. When two problems teach the same invariant, keep the one that adds the most new technique and put the other in the practice-only list. This keeps the repository large in coverage without becoming repetitive.

# 🗺️ DSA Pattern Mastery Roadmap

## Phase 0 — Programming foundations

Before heavy LeetCode practice:

- Variables and data types
- Conditions
- Loops
- Functions/methods
- Arrays/lists
- Strings
- Input/output
- Basic complexity
- Recursion basics

## Phase 1 — Core data structures

1. Arrays
2. Strings
3. Hash Map / Hash Set
4. Stack
5. Queue / Deque
6. Linked List
7. Trees
8. Heap / Priority Queue
9. Graphs
10. Trie

## Phase 2 — Core patterns

1. Hashing
2. Two Pointers
3. Sliding Window
4. Prefix Sum
5. Difference Array
6. Binary Search
7. Fast & Slow Pointers
8. Stack / Monotonic Stack
9. Heap / Top K
10. Intervals
11. BFS / DFS
12. Backtracking
13. Greedy
14. Union-Find
15. Topological Sort

## Phase 3 — Dynamic Programming

Study DP as families rather than one huge topic:

- 1D DP
- Grid / 2D DP
- Knapsack
- Subsequence DP
- Partition DP
- Interval DP
- State-machine DP
- Tree DP
- Bitmask DP

## Phase 4 — Advanced structures and algorithms

- Dijkstra
- Minimum Spanning Tree
- Fenwick Tree
- Segment Tree
- Advanced Trie
- Bit manipulation patterns
- Advanced graph algorithms

## Problem progression

For each pattern:

```text
Foundation → Core → Variation → Advanced → Combination
```

Do not move forward only because a problem was accepted. Move forward when you can explain **why the pattern works** and recognize it in a new problem.

## Platform integration

LeetCode, CodeChef, HackerRank, and MentorPick problems can be mapped into the same pattern taxonomy. The source does not change the learning method: identify the underlying technique, solve it, explain it, and connect it to neighboring problems.

## Language tracks

The repository intentionally maintains two parallel courses:

- `courses/java/` — Java syntax, collections, implementation patterns, and DSA
- `courses/python/` — Python syntax, built-ins, idioms, implementation patterns, and DSA

The algorithms remain conceptually aligned, while language-specific syntax is taught independently.
